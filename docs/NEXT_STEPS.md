# Дальнейшие шаги — инструкция (зафиксировано 2026-06-10)

Кодовая часть до вердикта завершена. Дальше — операционная рутина и одна
развилка по данным.

## Еженедельная рутина (оператор)

1. **Ставь по алертам.** Пришёл алерт → `python refresh_prices.py` (или открой
   рынок и сверь цену) → прочти правила резолва на Polymarket → проверь строку
   экспозиции в алерте (⚠️ЛИМИТ = категория перегружена, ставь меньше или
   пропусти) → ставь руками в пределах рекомендованного размера.
2. **Ничего не вноси в журнал руками.** Филл подтянется сам (fill_matcher,
   4×/день). Если через сутки позиция в журнале без `fill_source: onchain` —
   проверь, что ставил именно с кошелька `0xbd83...632f`.
3. **Реагируй на сигналы выхода** (Telegram, каждые 2ч): 🟡 = забрать часть,
   🟢 = закрыть всё, 🔴 = тезис умер, режь. После закрытия позиции вручную
   поменяй её `status` на `closed` в `event_journal.jsonl` — это единственное
   ручное действие (автоматизация закрытия по SELL-сделкам — кандидат на
   следующую итерацию).
4. **Раз в неделю:** `python verify_journal.py` — смотри, как копится выборка.

## Параметры — проверь один раз

- `config.py: BANKROLL = 3000` → поставь фактический банк (от него считаются
  проценты экспозиции).
- Секрет `POLYMARKET_PROXY_WALLET` в репо не обязателен (адрес зашит fallback'ом).

## Вердикт (~через 4–8 недель)

Когда `verify_journal.py` покажет **≥30 резолвнутых оценок в short-horizon
(≤45д)** срезе — читай блок «GROK vs MARKET (Brier)»:

- **Δ > +0.01 (Grok бьёт рынок)** → edge подтверждён. Следующая итерация кода:
  фракционный Kelly (¼–½) на категорийных лимитах, постепенный рост ставки.
- **Δ ≈ 0 или < 0 (не бьёт)** → edge нет, ставим против лучше откалиброванной
  толпы. Стоп новых ставок; менять источник оценки (другая модель / ансамбль /
  другой класс рынков) или закрывать стратегию — так же честно, как whale-copy.

До вердикта: пороги (EDGE_MIN 0.15, conf medium+, band 0.07–0.60) **не трогать**.

## Бэклог после вердикта (только если edge подтверждён)

- Автозакрытие позиций по SELL-сделкам из Data API (убирает последнее ручное

- Расширение band/горизонтов — только по данным калибровочного журнала.
